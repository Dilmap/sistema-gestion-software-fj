## Estructura del Proyecto
- `models/`: Clases abstractas, entidades de Cliente, Servicios (herencia y polimorfismo) y Reservas.
- `exceptions/`: Excepciones personalizadas para el control de errores.
- `logs/`: Registro de eventos y excepciones del sistema.
- `main.py`: Script principal con las 10 simulaciones requeridas.
